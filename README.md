# Next.js & Appwrite – Full Stack Course for Beginners

This repository follows the freeCodeCamp video **“Next.js & Appwrite – Full Stack Course for Beginners”**, developed by Hitesh Choudhary.

The course builds a full-stack authentication application with Next.js. It first covers a custom API using MongoDB, then introduces Appwrite as an alternative backend integration, and finishes with deployment.

## Course Topics

- Next.js basics and prerequisites
- Project structure, diagrams, and technology stack
- User signup and login
- Creating secure cookies with JWT authentication
- Middleware and protected routes
- Email service and user email verification
- Forgot-password flow
- Deployment with database connectivity
- Integrating Appwrite with Next.js
- Creating Next.js components that communicate with Appwrite
- Managing shared state with the React Context API
- Next steps for continuing full-stack development

## Technologies Covered

- **Next.js** — application framework and routing
- **MongoDB** — database used in the custom API portion
- **JWT and secure cookies** — authentication session concepts
- **Email service** — verification and password recovery flows
- **Appwrite** — backend services and authentication integration
- **React Context API** — sharing application state
- **Vercel** — deployment

> The exact technologies used in your own project depend on which course sections you have implemented.
